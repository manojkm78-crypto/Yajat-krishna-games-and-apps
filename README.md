## 🚀 How to Add Your Games/Apps

### Step 1: Upload Files to GitHub
1. Go to your repository on GitHub
2. Navigate to the `apps` folder
3. Click **Add file** → **Upload files**
4. Upload your APK file (e.g., `mygame.apk`)
5. Commit the changes

### Step 2: Upload Icon Image
1. Go to the `icons` folder
2. Click **Add file** → **Upload files**
3. Upload your app icon (PNG or JPG, e.g., `mygame.png`)
4. Commit the changes

### Step 3: Update apps/info.json
1. Go to `apps/info.json`
2. Click **Edit this file** (pencil icon)
3. Replace the content with your apps list (see format below)
4. Commit changes

## 📝 apps/info.json Format

```json
[
  {
```

## 💡 Tips

- Keep icon images square (512x512px is ideal)
- APK file names should be simple (no spaces)
- Description should be concise (max 300 characters)
- File sizes help users decide whether to download
